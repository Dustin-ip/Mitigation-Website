# NEUMitigates - School Safety and Security Reporting Tools

## Setup Instructions
1. Ensure you have Python installed.
2. Install the required dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python app.py`
4. Access the web app in your browser at `http://127.0.0.1:5000`.

## Testing the Roles
Log in via the portal by selecting the respective roles.
- **Student**: Can submit new reports (Category, Location, Person Involved) and view statistics.
- **Admin**: Can view incoming reports and "Assign task to department".
- **Department**: Can view assigned tasks and "Record a resolution" by uploading photo proof.
